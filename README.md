针对医学检验行业样本流转与物流配送场景，打造跨平台信息化解决方案。项目包含桌面端区域检验外送系统与移动端物流配送App，覆盖样本录入、实验室检验、物流配送全流程数字化管理。桌面端基于 Electron 实现跨平台部署（Windows/Mac），移动端基于 React Native 支持三类用户角色协同（兰卫工作人员、第三方物流、客商），实现样本信息实时追溯、配送任务智能调度，将物流配送效率提升 60%，样本流转准确率达 99.5%，有效降低人力物力成本。

项目职责：
1.桌面端开发：基于 Electron+Vue 搭建跨平台桌面应用架构，实现 Windows/Mac 双端适配；负责申请单、基础数据、系统管理三大核心模块的前端开发，通过 Element UI组件库快速构建表单录入、数据查询、权限管理等功能，保障样本信息准确录入与实验室业务流转
2、 移动端开发：基于 React Native+Redux 开发物流配送 App，实现任务、消息、我的三大模块，采用 React Navigation 构建
多页面路由体系；通过 Flex 布局适配不同尺寸移动设备，解决 Android/iOS 双端兼容性问题，确保 UI 一致性与交互流畅性
3、状态管理与数据联调：采用 Redux 实现 App 端全局状态管理，解决多角色用户数据共享与任务状态同步问题；基于 Axios 封
装统一请求层，完成桌面端与移动端接口联调，实现样本信息、物流任务、消息通知等数据实时交互
4、 跨平台技术实践：通过 Electron 主进程与渲染进程通信机制实现桌面端系统级功能（文件操作、打印等）；通过 React
Native 原生模块桥接实现移动端扫码、定位、推送等功能，积累跨平台开发经验，提升多端适配能力
