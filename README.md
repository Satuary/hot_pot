「月越新」火锅搭子社交匹配微信小程序，基于 uni-app（Vue 3 + TypeScript + Vite）开发的跨端小程序应用。以"一起吃火锅"为社交切入点，支持用户发布约饭需求、按火锅类型/请客方式/门店等条件发起匹配，通过 WebSocket 实时推送匹配结果，覆盖从发起匹配、等待确认到匹配成功的完整社交链路，并提供会员充值、订单交易记录等增值功能。

项目模块：

1、登录与资料：集成微信授权登录与手机号验证码登录，新用户引导完善个人资料（头像上传、昵称、位置信息等），基于高德定位 API 实现所在城市与附近地标自动定位，资料完善度校验贯穿全局路由守卫

2、匹配业务：支持发布约饭需求（时间、火锅类型、付费方式、门店选择等），发起匹配后进入等待队列，通过全局 WebSocket 长连接实时接收对方同意/拒绝/取消/超时等事件，倒计时持久化保证离开页面后状态不丢失，匹配成功后展示匹配详情卡片（约会时间、门店、双方头像）并可查看对方主页

3、个人中心：用户资料编辑、会员充值（含充值协议）、订单详情、退款申请、交易记录查询、设置与关于等模块，采用分包加载（subPackage）+ 分包预下载优化小程序包体积与启动速度

4、工程实践：基于 uni-preset-vue CLI 脚手架（Vue 3 + Vite + TypeScript）开发，编译产物输出至 dist/dev/mp-weixin；统一封装网络请求（统一错误提示）、WebSocket 消息订阅、本地存储与状态管理；全局注入图片 CDN 配置，规范静态资源管理
